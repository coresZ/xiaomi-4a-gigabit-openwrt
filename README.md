# 小米路由器 4A 千兆版（v1）刷官方 OpenWrt

在 **Mi Router 4A Gigabit v1**（原厂代号 R4A，MT7621，16MB 闪存）上，从原厂 2.28.38 刷官方 OpenWrt 25.12.6 的完整记录：教程、用到的全部文件、一个交互式一键刷机脚本，以及一套可选的自制代理 / 上网记录后台页面。

**先读 [`刷机教程.md`](刷机教程.md)。** 教程里逐项标明了哪些步骤我在真机上验证过、哪些没有。

> **v2 不能用这份固件。** 刷机有变砖的风险，操作前请先备份、并准备好救砖工具。

## 目录

| 目录 | 内容 |
|---|---|
| `1-OpenWrt固件/` | OpenWrt 25.12.6 与 25.12.4 的 v1 固件和官方 `sha256sums` |
| `2-开启SSH工具/` | xmir-patcher（第三方工具，用来在原厂系统里开 SSH） |
| `3-原厂固件与救砖/` | 原厂 v1 固件 2.28.38 和小米官方救砖工具 |
| `4-刷机前备份-仅限本机/` | **作者那一台路由器的整盘备份，只作留档，请勿使用，见下** |
| `5-刷机后可选/` | 中文语言包、Argon 主题 |
| `6-实际用过的脚本/` | 当时手工刷机用的 3 个脚本 |
| `7-自制代理与上网记录页面/` | 自制的 VLESS 透明代理页和上网记录页（可选）及源码 |
| `flash_openwrt.py` / `一键刷机.bat` | 交互式一键脚本：刷机、升级、安装自制页面（支持 `--dry-run` 演练） |
| `SHA256SUMS.txt` | 除 xmir-patcher 外全部文件的校验值 |

## 请注意

- **不要把 `4-刷机前备份-仅限本机/` 里的文件刷到你的路由器上。** 那是作者设备的整盘镜像，里面有作者路由器的 MAC 地址、Wi-Fi 校准数据和原厂时期的 Wi-Fi 名称与密码。刷到别的路由器会造成 MAC 冲突和 Wi-Fi 校准错误。**你需要自己的备份**，教程里有说明。
- 本仓库**没有设置许可证**。其中的 OpenWrt 固件遵循其自身的 GPL 等许可证；xmir-patcher、小米原厂固件和救砖工具是第三方文件，版权归各自所有者，版本和许可以其原发布处为准。
- 自己写的脚本和页面按"现状"提供，不保证适用于其他型号或系统版本。
