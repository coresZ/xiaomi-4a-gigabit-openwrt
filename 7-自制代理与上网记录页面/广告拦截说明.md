# 轻量广告拦截：dnsmasq 版

这是可选的第三个 LuCI 服务页。复用路由器原有 dnsmasq，不安装 AdGuard Home、curl 或另一个代理内核，也不新增常驻 DNS 服务。

## 能拦什么

- 针对独立广告、跟踪域名做 DNS 拦截，包含该域名的子域名。
- 支持手动拦截、白名单、一个小型规则源，以及网站 DNS 记录分析。
- 仅对使用路由器 DNS 的查询生效，不强制重定向设备 DNS，不解密 HTTPS。加密 DNS、HTTPDNS、直接访问 IP 或已经缓存的解析可能绕过。
- **不能保证去掉 YouTube 视频广告。** 广告和正常视频经常共享 `googlevideo.com` 等服务器；程序不会把 `youtube.com`、`googlevideo.com` 等正常视频域名当成默认广告规则。手机 YouTube App 的视频广告尤其不能承诺。
- 不做网页元素隐藏，无法替代浏览器内容拦截扩展。图片、登录、支付异常时，先关闭拦截或加入白名单。

## 使用

1. 传入文件后，让 rpcd 重新加载权限，刷新 LuCI，在「服务 → 广告拦截」打开页面。权限尚未更新时可退出后台重新登录。
2. 默认配置关闭拦截。点击「开启拦截」加载小型内置规则。DNS 服务需要短暂重启以读取配置；这不是重启路由器，也不会重启代理。
3. 「更新小型规则源」在后台下载、处理规则，不等待一个长时间的网页请求。失败时保留旧规则。不要向这个服务塞进几十万条规则。
4. 「手动规则与白名单」填域名或网址，点击对应按钮。中文域名由浏览器转换为 DNS 使用的 ASCII 形式。名单包含子域名；白名单优先。
5. 设备 DNS 缓存不会因修改规则立即消失；可以稍等或重新连接 Wi-Fi 后再测试。

开机恢复使用本地保存的规则，不依赖先下载规则。规则生成文件放在内存盘；配置和手动名单保存在闪存。正常重启保留文件；刷机、恢复出厂和保留配置升级不是同一回事。不要为了保留本服务把大代理内核塞进 sysupgrade 备份。

## 网站广告域名分析

这是**有边界的候选分析**，不是 IP 反查、完整网页抓包，也不是自动判断广告内容。

1. 在「上网记录」开启访问记录。
2. 用手机或电脑浏览目标网站。
3. 在广告拦截页输入网站域名，点「分析广告域名」。
4. 程序只读最近 15 分钟、最多 3000 条现有 DNS 记录，最多列 60 个候选：找出同一设备在目标网站 DNS 查询前 5 秒至后 45 秒出现、且命中内置广告域名分类的域名。
5. 页面会核对手动规则、父域名覆盖、内置/订阅规则和白名单，分别标记「已加入规则」「已被规则覆盖」「白名单放行」「待加入」。已有规则不重复勾选，状态读取失败时不会当成新域名。
6. 检查后勾选待加入的域名，点「加入勾选的广告域名」，一次提交并应用。成功后显示数量提示和屏幕下方通知，并立即更新条目标记；再次分析仍保留已有规则状态。

**DNS 查询记录不等于连接成功。** 设备请求一个已拦截域名时，dnsmasq 仍会记录这次查询，即使返回 NXDOMAIN；所以历史中再次出现该域名，不代表广告已经穿过拦截。页面的规则标记表示规则归属，不是每个客户端的实际连接验证。广告也可能换用其他未拦截域名、设备已有缓存或使用独立的加密 DNS，不能仅根据新出现的域名判断某条旧规则失效。

同一时间其他 App 的请求也可能出现在候选中。没有记录、设备使用加密 DNS、目标网站解析结果已缓存、广告来自同域名，都会导致找不到候选。找不到不代表没有广告，找到也不证明一定属于该网站。候选仅包含已知分类，不会将所有同时出现的第三方域名全部封掉。

分析不上传浏览记录，不联网抓取目标网站，也不修改「上网记录」原始数据。分析结果保留在当前浏览器页面；加入规则后，只有域名写入手动名单。

## 维护注意

- 总规则最多 4000 条，手动规则和白名单合计最多 256 条，每次批量添加最多 60 条。
- 固定使用 AdAway 小型 hosts 规则源，下载上限 256KiB，持久规则源缓存上限 100KiB；源变大或下载失败时保留旧规则。规则源超出条数预算时只保留限制内的一部分，不是完整订阅。
- 后台更新前要求可用内存至少 14000KB，启用和手动应用前至少 8000KB。启用期间每天 04:23 尝试更新；关闭后移除本服务的定时任务。
- 空间、内存和规则量都有上限；更新时的瞬时内存不能按脚本文件大小估算。
- 停用时只移除本服务生成的 dnsmasq 配置，不删除其他 DNS 设置或上网记录的日志设置。
- 别把手动名单写成整个公共 CDN、视频域名或大型主域名；误拦范围可能非常大。
- 安装包里的默认配置不含任何用户的浏览历史或私有域名。
