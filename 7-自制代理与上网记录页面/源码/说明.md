# 源码说明

`main.go` 是路由器上 `xr` 程序的全部自写代码，**不能单独编译**，它要放进 Xray-core 的源码树里。

## 为什么用 VS Code 打开会满屏红线

这个文件旁边没有 `go.mod`，也没有 Xray-core 的源码，编辑器的 Go 语言服务找不到
`github.com/xtls/xray-core/...` 和 `google.golang.org/protobuf/...`，就把每一条 import 都标红
（报错是 `BrokenImport … cannot find package … in GOROOT`）。**这不是代码错误。**
在下面的源码树里打开它，红线就消失了。

## 编译步骤

1. 取得 Xray-core **v26.10.21** 的源码（需要 Go 1.27）：
   `git clone --depth 1 --branch v26.10.21 https://github.com/XTLS/Xray-core.git`
2. 在源码树里打补丁（去掉 QUIC 嗅探和 Hysteria 入站，省约 0.5MB）：
   `git apply xray-core-v26.10.21-精简补丁.patch`
3. 把本目录的 `main.go` 放到源码树的 `mini5/main.go`。
4. 编译（给 mipsel 软浮点的路由器）：
   ```
   GOOS=linux GOARCH=mipsle GOMIPS=softfloat CGO_ENABLED=0 go build -trimpath -ldflags "-s -w -buildid=" -o xr ./mini5
   ```
5. 用 UPX 压缩：`upx --lzma --best xr`，压完约 4.3MB。

不打补丁也能编译，只是程序会大约 0.5MB。路由器上闪存很紧，所以我打了补丁。

## 它做什么

读订阅（v2rayN 通用格式），只保留 VLESS（Reality / WS+TLS / TCP+TLS），按节点名或序号选一个，
在本机起一个透明代理入口（`-port`）；可选 `-chain` 把所选节点当前置、再经过一个 socks5 / http / vless / ss 出口。
只处理 TCP。`-list`、`-stats`、`-check-chain` 是给脚本用的辅助命令。
